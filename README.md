# Primitive DB

Primitive DB — учебная консольная база данных на Python, поддерживающая управление таблицами и выполнение CRUD-операций.

Данные хранятся в JSON-файлах. Приложение поддерживает проверку типов, автоматическую генерацию идентификаторов записей, обработку ошибок, подтверждение удаления, измерение времени выполнения операций и кэширование запросов.

## Требования

- Python 3.12 или новее
- [uv](https://docs.astral.sh/uv/)

## Установка

Клонируйте репозиторий и перейдите в директорию проекта.

Установите зависимости и сам проект:

```bash
uv sync
```

## Запуск

```bash
uv run database
```

После запуска программа отображает справку с доступными командами и ожидает пользовательский ввод.

Для выхода используйте команду `exit`.

## Управление таблицами

Поддерживаются три типа данных: `int`, `str`, `bool`.

| Команда | Описание |
|---|---|
| `create_table <имя> <столбец:тип> ...` | Создание таблицы |
| `list_tables` | Список существующих таблиц |
| `drop_table <имя>` | Удаление таблицы |
| `help` | Справочная информация |
| `exit` | Завершение работы |

При создании таблицы автоматически добавляется столбец `ID:int`, если пользователь не указал его самостоятельно.

Пример:

```text
>>> Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>> Введите команду: list_tables
- users
```

Удаление таблицы требует подтверждения пользователя.

## CRUD-операции

Приложение поддерживает добавление, чтение, обновление и удаление записей.

### INSERT — добавление записи

```sql
insert into users values ("Sergei", 28, true)
```

Результат:

```text
Запись с ID=1 успешно добавлена в таблицу "users".
```

Столбец `ID` генерируется автоматически. При добавлении необходимо передать значения всех остальных столбцов в порядке их объявления.

### SELECT — чтение записей

Получение всех записей:

```sql
select from users
```

Получение записей по условию:

```sql
select from users where age = 28
```

Результаты выводятся в консоль с использованием библиотеки PrettyTable.

### UPDATE — обновление записей

```sql
update users set age = 29 where name = "Sergei"
```

Результат:

```text
Запись с ID=1 в таблице "users" успешно обновлена.
```

Изменение уникального идентификатора `ID` запрещено.

### DELETE — удаление записей

```sql
delete from users where ID = 1
```

Перед удалением программа запрашивает подтверждение:

```text
Вы уверены, что хотите выполнить "удаление записей"? [y/n]:
```

Ответ `y` подтверждает операцию. Любой другой ответ отменяет её.

### INFO — информация о таблице

```sql
info users
```

Пример результата:

```text
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0
```

### Правила ввода значений

- `int` — целые числа, например `28`, `-5`.
- `str` — строки в одинарных или двойных кавычках, например `"Sergei"`.
- `bool` — `true` или `false`, регистр не имеет значения (`TRUE`, `False` и другие варианты).
- Все поля при добавлении записи обязательны.
- Условия `WHERE` и присваивания `SET` используют оператор `=`.
- Одна команда `INSERT` добавляет одну запись.

## Хранение данных

Данные сохраняются между запусками программы.

В Linux используется директория:

```text
~/.local/share/primitive_db/
├── db_meta.json
└── data/
    ├── users.json
    └── ...
```

- `db_meta.json` содержит имена таблиц и описания столбцов.
- `data/<имя_таблицы>.json` содержит записи конкретной таблицы.

Файл записей создаётся при первом успешном добавлении данных. При удалении таблицы удаляется и соответствующий файл записей.

## Декораторы и кэширование

Для улучшения работы приложения реализованы следующие механизмы:

**`handle_db_errors`** — централизованная обработка исключений `KeyError`, `ValueError` и `FileNotFoundError`.

**`confirm_action`** — запрос подтверждения перед удалением таблиц и записей.

**`log_time`** — измерение времени выполнения операций `INSERT` и `SELECT` с помощью `time.monotonic()`.

Пример вывода:

```text
Функция insert выполнилась за 0.001 секунд
```

**`create_cacher`** — замыкание для кэширования результатов повторяющихся запросов `SELECT`.

При повторном одинаковом запросе может использоваться ранее сохранённый результат. После успешного изменения данных кэш сбрасывается.

## Структура проекта

```text
src/primitive_db/
├── __init__.py
├── main.py
├── engine.py
├── parser.py
├── core.py
├── utils.py
├── decorators.py
└── constants.py
```

Назначение модулей:

| Модуль | Ответственность |
|---|---|
| `main.py` | Точка входа |
| `engine.py` | Основной цикл и диспетчеризация команд |
| `parser.py` | Синтаксический разбор команд |
| `core.py` | Бизнес-логика и CRUD |
| `utils.py` | Работа с JSON и файловой системой |
| `decorators.py` | Декораторы и кэширующее замыкание |
| `constants.py` | Константы и пути |

## Проверка качества кода

В проекте используется Ruff.

Проверка:

```bash
uv run ruff check .
```

Проверка форматирования:

```bash
uv run ruff format --check .
```

## Сборка пакета

```bash
uv build
```

Результаты сборки помещаются в директорию `dist/`.

После установки пакета его консольная точка входа называется `database`.
