
# Primitive DB

Простая консольная база данных на Python.

## Установка

Для установки проекта требуется Python 3.12 или новее.

```bash
uv sync
```

## Запуск

```bash
uv run database
```

## Управление таблицами

Поддерживаемые типы данных: `int`, `str`, `bool`.

| Команда | Описание |
|---|---|
| `create_table <имя> <столбец:тип> ...` | Создать таблицу |
| `list_tables` | Показать таблицы |
| `drop_table <имя>` | Удалить таблицу |
| `help` | Показать справку |
| `exit` | Завершить программу |

При создании таблицы автоматически добавляется столбец `ID:int`, если он не был указан.

Метаданные сохраняются в файле `db_meta.json`.

## Пример использования

```text
>>> Введите команду: create_table users name:str age:int
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int

>>> Введите команду: list_tables
- users

>>> Введите команду: drop_table users
Таблица "users" успешно удалена.
```

## Сборка пакета
